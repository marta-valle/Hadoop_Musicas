# 🎧 Hadoop Músicas

Projeto de análise de dados musicais utilizando Hadoop e MapReduce.

## 📊 Objetivo

Analisar a popularidade das músicas por gênero utilizando processamento distribuído.

## ⚙️ Tecnologias utilizadas

- Hadoop (HDFS + MapReduce)
- Python
- Google Colab

## 📁 Estrutura do projeto

- `notebooks/`: execução no Colab
- `scripts/`: mapper e reducer
- `data/`: instruções para dataset
